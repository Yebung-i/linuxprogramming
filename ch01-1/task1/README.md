## UNIX 운영체제에 대하여 조사하시오.
1969년 벨 연구소에서 켄 톰슨과 데니스 리치가 개발한 운영체제, C 언어로 작성되어 다양한 하드웨어에 이식 가능하다. 또한 Windows 를 제외한 모든 운영체제의 조상격 되는 운영 체제이다. 이후 리눅스와 macOS 의 뿌리가 되었다. 
여러 사용자가 동시에 접속하여 여러 작업을 처리할 수있는 다중 사용자, 다중 작업 시스템이다.

## Linux, Windows, macOS 를 비교 설명하시오.
Linux 는 오픈소스, 무료인 운영 체제로서 서버 및 개발환경에 자유롭게 커스터마이징 하는것이 가능하다.
Windows는 상용 폐쇄형 OSㄹ서 일반 데스크톱 및 기업용 PC로 적합하며 널리 쓰인다.
MaxOs는 애플이 자체적으로 개발한 하드웨어에만 제공되는 강한 폐쇄형 OS로, 애플 제품 생태계화의 연동성이 뛰어나다.

## 우분투(Ubuntu) 리눅스에 대하여 조사하시오.
영국 기업인 Canonical 이 만든 Debian 기반 리눅스 배포판이다. 복잡하고 개발자들이 주로 다루던 리눅스를 초보자도 (상대적으로) 쉽게 사용할 수 있도록 설계되었다. (최신 LTS는 26.04)

## 임베디드 시스템용 운영체제로 리눅스가 적합한 이유를 설명하라.
오픈 소스이며 무료이기 떄문에 이미 널리 쓰이고 있으며, 라이선스 비용이 없고, 필요한 기능을 추가하거나 반대로 필요한 기능만 남기고 가볍게 최적화 하는 것이 가능하다. 다양한 하드웨어를 지원하며 커뮤니티 및 자료가 풍부해 공유기나 IoT 등에 널리 쓰인다.
