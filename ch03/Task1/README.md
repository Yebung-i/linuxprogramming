문자단위 커서이동 -> 앞, 뒤, 맨앞, 맨뒤 : ctrl + b / ctrl + f / ctrl + a / ctrl + e <br>
단위단위 커서 이동 -> 앞, 뒤 : alt + b / alt + f <br>
현재 위치 문자 삭제 : ctrl + d <br>
뒤에 있는 문자 삭제 : ctrl + h <br>
뒤에 있는 단어 삭제 : ctrl + w <br>
자르기 및 붙여넣기 : ctrl + k (전체는 ctrl + u) / ctrl + y <br>
화면 잠금 및 해제 : ctrl + s / ctrl + q <br>
실행종료 : exit <br>
화면삭제 : ctrl + l <br>
