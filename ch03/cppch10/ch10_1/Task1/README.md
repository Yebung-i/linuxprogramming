## 템플릿 함수의 2가지 매개변수는?
템플릿 매개변수 : 함수가 다루는 자료형을 받는 매개변수
함수 매개변수 : 함수 안에서 사용할 값을 받는 매개변수

## 템플릿 매개변수의 용도는?
함수가 다루는 자료형을 일반화하기 위한 것, 자료형만 다르고 나머지 코드가 같은 여러 함수를 하나의 틀로 합칠 수 있음

## 함수 매개변수의 용도는?
호출하는 쪽에서 함수 안에서 사용할 값(함수 인자)을 전달받기 위한 것, 값만 다른 여러 함수는 하나의 함수로 합쳐 중복을 방지한다.

## 템플릿함수의 정의는 호출과 같은 소스코드에 존재해야 하는 이유는?
템플릿 함수 호출 문장을 컴파일할 때 그 정의로부터 구체화를 수행한다. 정의가 다른 소스파일에 있으면 호출하는 파일에서 정의를 찾을 수 없어 구체화가 불가능하고 링크 때 함수를 찾지 못하므로, 헤더파일에 정의를 작성하고 호출하는 코드에서 헤더파일을 include하여 호출과 정의가 같은 코드에 존재하게 해야 한다.
