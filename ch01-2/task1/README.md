## 가상머신이란 무엇인가?
하나의 물리적 컴퓨터(호스트) 상에 소프트웨어로 구축한 가상의 컴퓨터로, 그 안에서 별도의 운영체제와 프로그램을 독립적으로 실행할 수 있도록 해주며, 호스트의 CPU,메모리,저장장치 등 역시 가상화해 나누어 쓰며 하나의 물리 서버에서 여러 개의 가상머신을 동시에 띄울 수 있다.

## 가상머신을 사용하는 이유를 설명하라.
하나의 하드웨어로 여러 운영체제나 환경을 동시에 테스트 및 운영할수 있어 자원 활용도가 높아지며, 실제 시스템에 영향을 주지 않고, 가상 환경에서 실험이나 개발하는 것이 가능한데, 이는 문제가 생기면 스냅샷으로 되돌리기 쉽다는 뜻이다.

## WSL2가 다른 가상머신 소프트웨어와 비교하여 장점이 무엇인가?
WSL2의 장점은 다음과 같다.
Linux와의 호환성 : Linux 커널을 탑재하였기에 Docker, 대규모 컴퓨터 파일 등의 기능들이 완벽하게 작동된다.
속도 : Windows 파일 시스템과의 연동 속도가 비약적으로 상승하여 파일 읽기, 쓰기 작업이 빨라졌다.
자원 소모 낮음 : 메모리와 CPU를 필요한 만큼만 동적 할당하기에 PC 성능 저하가 거의 없다. 
IDE와의 연동성 : VS Code, IntelliJ 등의 Windows에 설치된 개발 도구로 Linux 내부 코드를 직접 수정하고 디버깅 하는 것이 가능하다. 

## GUI, CLI의 장단점을 비교 설명하시오.
GUI는 아이콘과 마우스로 직관적인 조작이 가능해 배우기 쉽고, 일반적인 사용자들에게 매우 친숙하지만, 화면을 그리는 것에 자우너이 더 투입되며 반복 작업 자동화가 어렵다 (ex: 파일 100개의 이름 바꾸기).
반면 CLI는 배우는 것에 시간이 걸리고 명령어를 외워야 하므로 처음 사용하는 사람은 큰 어려움을 느끼지만, 자원 소모가 GUI와 비교해 적으며 반복 작업 등을 스크립트로 자동화하기 좋고, 원격 서버 관리에 유리하다.


## CLI방식의 인터페이스가 GUI방식보다 처리속도가 빠른 이유를 설명하라.
상기했듯, GUI는 화면에 창이나 아이콘, 애니메이션 등을 그려내는 작업이 피요하기에, 이 렌더링 작업에 CPU와 메모리를 추가로 사용해야 하지만, CLI는 텍스트만 주고받기dp 그래픽 처리 부담이 거의 없으며 자원 소모도 적다. 그만큼 가용 자원이 실제 명령 처리에 더 집중되어 GUI보다 빠른 것이다.

## 리눅스에서는 왜 CLI방식을 주로 사용하는가?
리눅스에서 프로그램 개발 시에는 Windows의 Visual Studio와 같은 GUI 도구를 사용하지 않고 CLI 도구 (vi, gcc, make) 를 주로 사용하기 때문이다.
또한 리눅스는 주로 서버컴퓨터의 OS로 사용되기에, 서버컴퓨터는 주로 데이터 센터에 위치하여 사용자는 네트워크로 원격 접속하여 작업을 처리한다. << 이 경우에는 GUI 사용시 통신 데이터량이 많아 속도가 느려지기에, 반대로 통신 데이터량이 작은 텍스트를 주고받는 CLI 도구를 쓰는 것이 처리속도가 빠르기 때문이다.
