# 하드링크와 심볼릭 링크의 차이를 설명하라.
- 하드링크는 동일한 데이터를 가리키는 또 다른 이름이라고 보면 된다. 즉, 원본 파일 역시 하드링크이며, 하드 링크 생성 시 원본파일의 새로운 이름이 하나 더 생성된다.  <= 어느 쪽이 원본인지 구분 불가능, 모두 원본 파일을 부르는 이름이기 때문
  
- 심볼릭 링크는 디렉터리를 링크할 수 없고, 서로 다른 디스크에 걸쳐 만들수 없던 하드링크를 보완하는 개념으로, ln 명령어 사용 시 -s 옵션으로 만들 수 있다. 심볼릭 링크 파일에 접근하면 원본 파일에 접근이 가능하며, 삭제 하더라도 원본 파일엔 영향 X, 단 원본을 지우면 안된다.
