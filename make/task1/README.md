## make, Makefile을 구분하여 차이점을 설명하라
- make 는 유닉스/리눅스에서 주로 쓰는 프로그램 빌드 자동화 도구로서, 사용자가 명령어를 입력하는 과정을 자동화한다. 컴파일러는 아니다.
- Makefile은 프로그램을 컴파일 및 링크하는 방법을 알려주는 빌드 설정 파일이며, make를 실행하기 前 먼저 작성해야함

## 프로그램 개발과정에서 GNU Make는 왜 필요한가?
소스 파일이 여러개이고 make가 없다면, 컴파일과 링크 명령을 매번 직접 입력해야 하지만, make가 있다면 make 한 줄 만 입력해주면 된다. 
또한 명령이 길고 많아져 누락과 오타가 생기기 쉬운데, make는 Makefile에 한 번 적어 두면 되기에 편리하다.

## 윈도우에서 사용한 Visual studio에서는 make의 역할을 누가하는가?
VS의 빌드 시스템이 make 역할을 한다.
