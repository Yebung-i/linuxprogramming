## ls 명령어의 4가지 옵션 -a, -l, -F, --help을 설명하고 각각 실행예를 첨부하시오.
- -a : 숨김 파일을 포함해 모든 파일과 디렉터리를 표시한다.
<img width="826" height="77" alt="image" src="https://github.com/user-attachments/assets/f1a547b4-6e2f-41bd-8060-f26a48c1a8a2" />

- -l : 파일의 소유자, 그룹, 크기, 수정 시간 등의 상세 정보를 표시함
<img width="743" height="363" alt="image" src="https://github.com/user-attachments/assets/f81c7185-33a7-4b2e-a191-7fc5162d5d13" />


- -F : 파일 종류를 구분할 수 있도록 이름 끝에 기호를 붙여 표시한다. (/ : 디렉터리, * : 실행 파일 등등)
<img width="528" height="76" alt="image" src="https://github.com/user-attachments/assets/ec573174-e6d1-4d0b-a565-f46d6cf0b757" />

- --help : ls명령어의 사용법과 지우너하는 모든 옵션 목록을 출력한다.
<img width="928" height="271" alt="image" src="https://github.com/user-attachments/assets/7c8ed7b8-a361-41be-90a8-39d9ce10bf85" />

## 경로확장 문자 *, ?의 의미를 설명하고 각각 실행예를 첨부하시오.
- * : 임의의 문자열을 의미하며, $ ls file* 은 file로 시작하는 모든 파일 목록을, $ ls *.txt 는 확장자가 .txt인 모든 파일 목록을 출력한다.

<img width="936" height="52" alt="image" src="https://github.com/user-attachments/assets/b93f89a6-d7e3-4bc7-a839-52706833c88f" />


- ? : *와 비슷하지만 임의의 한 문자만을 의미한다. (?의 개수 == 글자의 개수)
