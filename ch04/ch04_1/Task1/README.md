# 단어 또는 기호의 의미를 설명하라 
## 디렉터리
- 여러 개의 파일을 모아 놓은 파일을 의미한다. 폴더의 개념과 같다.
## 서브 디렉터리
- 디렉터리 내부에 포함되어 있는 또 다른 디렉터리를 의미한다. 
## 작업 디렉터리
- 현재 위치하여 작업하는 디렉터리를 말함, pwd로 확인 사능하며 프롬포트 문자열에서 $로 표시된다.
## 홈 디렉터리
- 사용자별로 할당되는 개인용 디렉터리를 의미한다. (ex : 이름이 yechan 이면 홈 디렉터리는 /home/yechan 이 된다.)
- 사용ㅈ는 홈 디렉터리 내부에서 자유롭게 파일 혹은 디렉터리를 작성하고 관리할 수 있다. 
## ~
- 홈 디렉터리를 나타낸다. 
## .
- 현재 작업 디렉터리를 의미한다.
## ..
- 부모 디렉터리를 위미한다. (상위 디렉터리 표시)
## /
- 처음 / 는 루트 디렉터리, 그 다음부터 나오는 / 는 디렉터리를 구분하는 문자이다.
## 상대경로
- 현재 작업 디렉터리를 기준으로 표기하는 상대적인 경로이며, / 없이 시작하는 경로명을 의미한다.
## 절대경로
- 루트 디렉터리 (최상위 경로) 부터 현재 경로에 해당하는 파일에 이르기까지의 모든 경로를 표시하는 것이다. (반드시 / 로 시작한다.)
- ex : /home/airlab/yechan/work/helloWorld.c
