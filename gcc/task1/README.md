## 정적 라이브러리
- 라이브러리 코드를 실행 파인 안에 복사하여 포함한다.
- 컴파일 시점에 링커가 라이브러리 함수를 실행 파일에 연결시킴
- 실행 파일만 있으면 독립적으로 실행되며 외부 라이브러리에 의존하지 않지만, 실행 파일의 크기가 큼

## 동적 라이브러리
- 실행 파일에는 참조 정보만 두고, 실행 시 외부 라이브러리 파일을 불러와 사용하는 라이브러리임
- 실행 시 동적 링커가 라이브러리 함수를 연결
- 실행파일의 크기가 작고, 여러 프로그램이 하나의 라이브러리를 메모리에서 공유하여 메모리가 절약되지만, 실행 환경에 해당 라이브러리가 없거나 버전이 다르면 실행이 안된다.

# gcc 옵션
## -I <경로>
- 헤더파일을 찾을 디렉터리를 추가한다.
## -l <이름>
- 링크할 라이브러리 파일을 찾을 디렉터리를 추가함.
## -g
- 실행 파일에 디버깅 정보(소스 줄 번호, 변수 이름 등)를 포함한다.
## -v
- 컴파일 과정을 자세히 출력한다. 내부적으로 실행되는 명령이나 헤더 및 라이브러리 섬색 경로와 gcc 버전 등 . . .
